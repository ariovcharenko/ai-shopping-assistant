# Product Search Evaluation System

This directory contains tools for evaluating and analyzing the performance of your product search engine. The system helps you understand how well your search engine interprets natural language queries and matches them to products in your catalog.

## Overview

The evaluation system consists of several components:

1. **Improved Evaluation Script** - Analyzes queries against the product catalog with case-insensitive and partial matching
2. **Missing Product Types Extractor** - Identifies product types expected in queries but missing from the catalog
3. **Visualization Tool** - A web-based UI for exploring evaluation results and insights
4. **Tagged Results** - Detailed analysis of each query with failure categorization

## Files

- `improved-evaluate-queries.py` - Main evaluation script that implements semantic matching
- `extract_missing_product_types.py` - Script to identify missing product types
- `visualization/index.html` - Web-based visualization tool
- `eval-tagged-log.jsonl` - Tagged results with failure categorization (generated by the evaluation script)
- `evaluation-summary.json` - Summary metrics (generated by the evaluation script)
- `missing_product_types.json` - Report of missing product types (generated by the evaluation script)

## How to Use

### Running the Evaluation

1. Make sure your product catalog is up to date in `server/data/productCatalog.js`
2. Make sure your evaluation dataset is available at `server/data/datasets/eval-dataset.jsonl`
3. Run the improved evaluation script:

```bash
python ResearchEvaluation/improved-evaluate-queries.py
```

This will:
- Load the evaluation dataset and product catalog
- Perform matching with case-insensitive and partial matching
- Generate detailed logs with tags for each query
- Calculate and save summary metrics
- Identify missing product types

### Analyzing Missing Product Types

If you want to specifically analyze missing product types:

```bash
python ResearchEvaluation/extract_missing_product_types.py
```

This will generate a detailed report of product types that are expected in queries but not found in the catalog.

### Visualizing Results

To view the evaluation results in a user-friendly interface:

1. Start the visualization server:
```bash
python ResearchEvaluation/serve_visualization.py
```

This will:
- Start a local HTTP server on port 8000
- Automatically open your browser to the visualization page
- Serve the necessary JSON files with proper CORS headers

2. The visualization provides:
   - Summary metrics dashboard
   - List of missing product types
   - Sortable and filterable query results
   - Tag-based filtering
   - Search functionality

## Understanding the Results

### Evaluation Summary

The `evaluation-summary.json` file contains key metrics:

- `total_queries`: Total number of queries evaluated
- `queries_with_matches`: Number of queries that matched at least one product
- `match_percentage`: Percentage of queries with matches
- `avg_matches_per_query`: Average number of product matches per query
- `top_unmatched_product_types`: Most common product types that didn't match anything
- `unmatched_filters`: Filters that were never found in any product

### Tagged Results

The `eval-tagged-log.jsonl` file contains detailed information about each query, including:

- The original query
- Expected output (product type, filters, etc.)
- Matched products (if any)
- Tags indicating why a query failed to match:
  - `product_type not in catalog`: The expected product type doesn't exist in the catalog
  - `wrong category`: The expected category doesn't match any product
  - `wrong subcategory`: The expected subcategory doesn't match any product
  - `no overlapping filters`: None of the expected filters match any product attributes
  - `filters mismatch`: Some filters matched but others didn't
  - `expected output not found`: General failure case
  - `partial filter match`: Some but not all filters matched
  - `full match`: All expected criteria matched

## Improving Your Search Engine

Based on the evaluation results, you can improve your search engine by:

1. **Adding Missing Product Types**: Use the `missing_product_types.json` report to identify product types that should be added to your catalog.

2. **Enhancing Semantic Matching**: Modify your search algorithm to better handle variations in product type names and filter descriptions.

3. **Expanding Filter Coverage**: Add more attributes to your product catalog to cover the filters identified in the `unmatched_filters` list.

4. **Improving Category Mapping**: Ensure your category and subcategory structure aligns with how users describe products in their queries.

## Customization

You can customize the evaluation system by:

- Modifying the matching logic in `improved-evaluate-queries.py`
- Adding new tags or metrics to the evaluation
- Enhancing the visualization tool with additional features
